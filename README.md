# CT-GO

Windows 本地维护工具。查看内存、磁盘、启动项与系统状态，并按需清理临时文件与缓存。

本仓库只存放安装包，不包含源代码。

## 下载

前往 [Releases](https://github.com/pengding-1/CT-GO-Download/releases/latest) 下载最新版本：

- `CT-GO-Setup.exe`：安装版，推荐日常使用
- `CT-GO-Portable.exe`：便携版，无需安装
- `SHA256SUMS.txt`：下载后核对文件完整性

系统要求：Windows 10 / 11，64 位。

## 安装

1. 下载 `CT-GO-Setup.exe`。
2. 双击运行，按提示完成安装。
3. 若 Windows 提示未知发布者，选择“更多信息”后继续。

关闭主窗口后程序会留在系统托盘继续运行；双击托盘图标重新打开，右键菜单可重启或退出。

## 功能

- 总览：内存压力、系统盘余量、启动项数量、可回收空间
- 内存与进程：按应用归并进程，显示实例数、内存和 CPU
- 启动项：查看并开关开机启动项
- 磁盘分析：按磁盘统计顶层目录和文件类型占用
- 网络检测：公网延迟、DNS 解析、活动网卡和系统代理
- 系统诊断：硬盘健康、实时防护、异常设备和近期系统错误
- IT 工具：快捷分盘、磁盘管理、设备管理器、系统信息和任务管理器

## 隐私

- 进程、磁盘和文件数据只在本机读取，不上传
- 只有主动点击网络检测时，才会访问固定的测试地址
- 清理范围限定在临时文件和缓存，个人文件不会被自动删除

## 注意

安装包尚未进行代码签名，Windows SmartScreen 可能提示未知发布者。

每个版本都附有 `SHA256SUMS.txt`，下载后可核对文件完整性。
